# Ledger

A simple iOS spending tracker. Log a purchase in two taps; see where the month went.

<img src="docs/screenshot.png" width="300" alt="Ledger" />

## Develop

```bash
npm install
npx expo run:ios   # first run, or after native changes
npx expo start     # JS-only changes after that
```

Lessons learned live in [FRICTION-LOG.md](FRICTION-LOG.md) and [expo-friction.md](expo-friction.md).
